Playground

Explore how RenderPDF.js turns browser-rendered HTML into a PDF. Import or paste a document, inspect the live preview, then export it alongside a jsPDF comparison. Everything runs in your browser.

Current limits

Use static HTML and CSS with inline PNG or JPEG images. Scripts and external resources are unsupported. RenderPDF.js supports an experimental subset of CSS and pagination; unsupported input may stop an export. The jsPDF comparison stays at A4 with 24 CSS px margins even when you edit RenderPDF.js options.

Fonts and profiling

Register local TrueType font bytes when the document requests a face that is not bundled. The preview and both exporters can then use the same font.

Document font files

Register matching local TTF files when a document uses a font that is not bundled. Files stay in this browser session. Missing faces may be substituted and reported.
