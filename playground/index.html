RenderPDF.js / jsPDF

Compare HTML-to-PDF exports

Upload HTML, inspect the preview, and download PDFs from both libraries with one click. Compare conversion time and file size. Your document is processed locally in the browser.

01 / Input

Your document

Choosing an example replaces the editor and preview. Load example restores the selected example after edits or an upload.

A UTF-8 .html or .htm file, up to 10 MiB.

You can also edit the loaded HTML or paste a complete static document with CSS. Scripts and external resources are unsupported; embed PNG/JPEG images as data URLs. Unavailable images are marked in the preview and block export until replaced.

Document font files

Font files are optional. Register matching local TTF files to preserve the HTML font in RenderPDF.js. Without a matching file, RenderPDF.js can use its base font and report the substitution; the preview and PDF may then look different. Files stay in this browser session.

      Applies when HTML requests a font without matching registered bytes. The RenderPDF.js result reports FONT_SUBSTITUTED in fallback mode. jsPDF handles missing fonts separately, so compare the downloaded PDFs as well as their times.

        Comparison settings

        Both libraries receive the same preview and available registered font bytes, A4 pages, and 24 CSS px margins. Missing fonts may be substituted differently. RenderPDF.js omits outer shadows and some table styles by default; the rejection checkbox makes those effects fail instead.
